
# AI Learning Roadmap Generator 🎓

An AI-powered application that generates personalized learning roadmaps.

## Features
- Select any learning domain.
- Choose Beginner, Intermediate or Advanced level.
- Select learning duration.
- Set daily study hours.
- Generate personalized learning plans using Grok AI.
- Get practical projects and learning resources.
- Download your generated roadmap.

## Technologies
- Python
- Streamlit
- xAI Grok API
- GitHub
